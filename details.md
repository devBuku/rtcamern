Backend
M - MongoDB (database)
E - Express (web server (web framework))
N - Node (Javascript runtime)
Socket.io - to make the real time features work (like typing indicator)
Resend - Email service to send email verification and password reset emails
Arcjet - To implement rate limiting
Jsonwebtoken - To implement authentication and authorization
Cloudinary - To store images and videos


Frontend
R - React (Frontend library)
Tailwind CSS and DaisyUI - For styling the frontend


Both backend + frontend is be using javascript
